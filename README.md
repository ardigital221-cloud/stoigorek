# CineTrack — Сервис учета и статистики сериалов/фильмов

Премиальный трекер просмотренных сериалов и кино с личной статистикой, интерактивным календарем релизов, игровой системой достижений и симуляцией монетизации (CPA/Premium).

[![Deploy to Render](https://render.com/images/deploy-to-render.svg)](https://render.com/deploy?repo=https://github.com/ardigital221-cloud/pror)

## 🚀 Возможности MVP

- **Быстрый тестовый вход**: авторизуйтесь в один клик под тестовым аккаунтом (`test@test.ru` / `test`) с предзаполненными данными.
- **Учет и трекинг**: добавляйте фильмы/сериалы в списки по статусам («Смотрю», «Просмотрено», «В планах», «Бросил»), отмечайте серии и выставляйте оценки от 1 до 10.
- **Интерактивная статистика**: личный дашборд с расчетом потраченного времени и динамической SVG-диаграммой любимых жанров.
- **Календарь релизов**: расписание выхода новых серий и премьер прямо в интерфейсе.
- **Монетизация**:
  - **Premium подписка (100 руб/мес)**: симуляция оплаты, скрывающая рекламу и открывающая PRO-аналитику.
  - **CPA партнерство**: реферальные переходы по кнопке «Где посмотреть?» с симуляцией редиректа на Кинопоиск / Иви.
- **Геймификация**: система наград (ачивок) с начислением очков и всплывающими тост-уведомлениями.
- **Админ-панель (симуляция)**: войдите под `admin@admin.ru` / `admin`, чтобы одобрять запросы пользователей на добавление контента.

## 🛠 Стек

- HTML5 + Vanilla CSS3 (Liquid Glass, Blur, неоновые градиенты)
- Vanilla ES6 JavaScript (модульная архитектура, localStorage для сохранения состояния)
- Render Blueprint (`render.yaml`) для мгновенного развертывания

## 📁 Структура проекта

```
pror/
├── index.html          — Главный макет SPA
├── render.yaml         — Конфигурация для Render.com
├── css/
│   └── tracker.css     — Стилизация и анимации (Glassmorphism)
└── js/
    ├── config.js       — База данных сериалов, ачивки и настройки
    ├── state.js        — Управление сессиями, списками и баллами
    ├── ui.js           — Рендеринг интерфейса и SVG графиков
    └── app.js          — Точка входа в приложение
```

## 🚀 Локальный запуск

Запустите локальный статический сервер в папке проекта:

```bash
npx serve .
# или
python -m http.server 8000
```

## ☁️ Деплой на Render.com

Для автоматического развертывания на Render:
1. Нажмите на кнопку **Deploy to Render** выше.
2. Подключите ваш репозиторий GitHub.
3. Render автоматически определит статический сайт на основе файла `render.yaml` и опубликует его.
